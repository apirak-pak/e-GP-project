# แดชบอร์ดประกาศ e-GP

โปรแกรมที่ใช้งานอยู่คือ `egp_live` ซึ่งรับคำตอบ API จากเว็บไซต์ e-GP ผ่านส่วนขยาย Edge และเก็บใน `data/egp_live.db` โดยตรง หน้าเว็บอ่านข้อมูลจากฐานนี้เท่านั้น

## เริ่มใช้งาน

1. เปิด PowerShell ในโฟลเดอร์นี้ แล้วรัน `./run.ps1` หรือ `python -m egp_live.server` (ต้องมี Python 3.10 ขึ้นไป)
2. เปิด `http://127.0.0.1:8502/` ใน Edge
3. หากยังไม่ได้ติดตั้งส่วนขยาย ให้เปิด `edge://extensions` เปิด Developer mode แล้วเลือก **Load unpacked** ที่โฟลเดอร์ `egp_live/extension`
4. ทำตามขั้นตอนเชื่อมตัวรับ API และดึงข้อมูลใน [คู่มือแดชบอร์ด](egp_live/README.md)

เปิด Edge และแท็บ e-GP ค้างไว้ระหว่างดึงข้อมูล การเปิดหรือกรองแดชบอร์ดอ่านข้อมูลในเครื่อง ไม่เรียก API เพิ่ม

## โครงสร้างที่ใช้งาน

- `egp_live/` — เซิร์ฟเวอร์ เว็บ และส่วนขยาย Edge ของแดชบอร์ดล่าสุด
- `data/egp_live.db` — ข้อมูลจริงที่แดชบอร์ดอ่านและบันทึก
- `tests/test_egp_live.py` และ `tests/test_egp_live_extension.cjs` — การทดสอบของแดชบอร์ดล่าสุด
- `unused/legacy_dashboard/` — โปรแกรม DGA เดิม เอกสารและเครื่องมือที่ไม่ได้ใช้กับแดชบอร์ดล่าสุด
- `unused/data/` — ฐานข้อมูลเดิม สำเนา ข้อมูลทดลอง และบันทึกการทำงานเดิม

ไฟล์ใน `unused/` เป็นที่เก็บพัก ไม่ได้ลบ และแดชบอร์ดล่าสุดไม่อ่านจากที่นั่น หากต้องย้อนดูข้อมูลเดิม ให้ตรวจคำอธิบายใน `unused/legacy_dashboard/README.md`

## การย้ายไปทำงานบนเซิร์ฟเวอร์

เริ่มจากตัวทดลอง `collector_probe` บน GitHub Actions เพื่อพิสูจน์การเข้าถึง e-GP จากคลาวด์โดยไม่ใช้เซสชันในเครื่องผู้ใช้ ดู [แผนและวิธีอ่านผล](docs/SERVER_READINESS.md) ตัวทดลองนี้ไม่แก้ฐานข้อมูลและยังไม่ใช่ตัวรับ production
