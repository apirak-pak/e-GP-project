# e-GP Project Radar — ต้นแบบบนเครื่อง

เว็บ Dashboard สำหรับค้นหาโครงการตามจังหวัด ประเภทงาน สถานะ และช่วงราคา พร้อมฐานข้อมูล SQLite ในเครื่อง รองรับการดึงข้อมูลจริงจากบริการ EGP-CONTRACT ของ DGA แบบสั่งเองผ่าน PowerShell ข้อมูลตัวอย่างมีป้ายกำกับในหน้าเว็บ

คำอธิบายแหล่งข้อมูลอยู่ใน [DATA_SOURCES.md](docs/DATA_SOURCES.md) และผังโค้ดสำหรับคนรับงานต่ออยู่ใน [ARCHITECTURE.md](docs/ARCHITECTURE.md)

เมื่อมี API Key แล้ว คัดลอก `.env.example` เป็น `.env` และใส่ Key ที่ `DGA_API_KEY=` ในไฟล์ `.env` บนเครื่องของคุณ สคริปต์อ่าน Key จาก `.env` โดยไม่แสดง Key ดูขั้นตอนใน [DATA_SOURCES.md](docs/DATA_SOURCES.md)

## เริ่มใช้งาน

1. เปิด PowerShell แล้วเข้าโฟลเดอร์โปรเจ็คด้วย `cd 'C:\DDDDDDDDDDDDD\e-GP project'`
2. รัน `python -m app.server` แล้ว **เปิดหน้าต่าง PowerShell นี้ค้างไว้** เพราะการปิดหน้าต่างจะหยุดเว็บ วิธีนี้ใช้ได้แม้ Windows บล็อกไฟล์ `.ps1` หากเครื่องอื่นยังไม่มี Python ให้ติดตั้ง Python 3.10 ขึ้นไปก่อน
3. เปิด <http://127.0.0.1:8501> ในเบราว์เซอร์ของเครื่องเดียวกัน ถ้าขึ้นว่าเชื่อมต่อไม่ได้ ให้กลับไปดูว่า PowerShell จากข้อ 2 ยังเปิดอยู่หรือไม่ แล้วรันคำสั่งอีกครั้ง
4. ใช้ตัวกรองบนหน้าเว็บกับข้อมูลที่มีอยู่ หรือเพิ่มโครงการ/นำเข้า CSV ของคุณเอง หากฐานข้อมูลว่างจึงจะมีปุ่ม **โหลดข้อมูลตัวอย่าง**
5. หยุดโปรแกรมด้วย `Ctrl+C` ใน PowerShell

## ดึงข้อมูลจริงจาก EGP-CONTRACT

เปิด PowerShell อีกหน้าต่างในโฟลเดอร์โปรเจ็ค แล้วรัน `python -m app.sync_egp --year 2568 --limit 20` จากนั้นรีเฟรชหน้าเว็บ ปีที่ระบุคือ **ปีงบประมาณที่ทำสัญญา** ไม่ใช่ปีประกาศงานใหม่ ตัวอย่างกรองวงเงินงบประมาณ 100–300 ล้านบาท: `python -m app.sync_egp --year 2568 --min-budget 100000000 --max-budget 300000000 --limit 20`

แต่ละครั้งส่งคำขอ **หนึ่งครั้ง** พร้อม `limit` และ `offset` ตามที่ระบุ โปรแกรมไม่จำกัด `limit` เองแล้ว แต่ API อาจจำกัดจำนวนรายการที่ส่งกลับหรือปฏิเสธคำขอขนาดใหญ่ ถ้าต้องการหน้าถัดไปใช้ `--offset 20` เมื่อรอบแรกใช้ `--limit 20` คำค้นเริ่มต้นคือ `จ้างก่อสร้าง` เปลี่ยนได้ด้วย `--keyword '...'` การรันซ้ำด้วยรหัสโครงการเดิมจะอัปเดตข้อมูลเดิม ช่วงราคาที่ใช้ดึงจาก API เป็น **วงเงินงบประมาณ** ส่วนตัวกรองบนหน้าเว็บเลือกได้ทั้งวงเงินงบประมาณ ราคากลาง และราคาที่ตกลงจ้าง

ดูจำนวนครั้งที่สคริปต์ของโปรเจ็คพยายามส่งคำขอ **นับจากวันที่เพิ่มตัวนับ** ด้วย `./api_usage.ps1` จำนวนนี้เก็บใน `data/api_requests.jsonl` โดยไม่เก็บ Key และรวมคำขอที่ API ตอบผิดพลาด ตัวนับนี้ไม่รวมการเรียกจากที่อื่นหรือก่อนเพิ่มตัวนับ และไม่ใช่ยอดโควตาทางการของ DGA การรีเฟรชเว็บหรือกรองข้อมูลบนหน้าเว็บไม่เรียก DGA เพิ่ม

หลังดึงข้อมูล สคริปต์แสดง feedback ที่ API ส่งกลับ ได้แก่ HTTP status, `success`, จำนวนรายการในหน้านั้น และจำนวนผลค้นหาทั้งหมด หากมี header โควตาที่เป็นตัวเลขจะแสดงโควตาคงเหลือด้วย แต่รอบที่ทดสอบล่าสุด API ไม่ส่งค่าคงเหลือใน header ที่ตรวจ

บริการ EGP-CONTRACT นี้เน้นข้อมูลโครงการที่มีสัญญาแล้ว จึง **ยังไม่ใช่แหล่งประกาศงานใหม่หรือสถานะระหว่างประมูลที่ครบถ้วน** คำว่า “สัดส่วนผู้ชนะ” ในหน้าเว็บหมายถึงสัดส่วนในข้อมูลที่นำเข้าและตรงกับตัวกรองเท่านั้น ข้อมูลที่นำเข้าปัจจุบันเป็นเพียงบางส่วนของผลค้นหา จึงยังใช้ประมาณส่วนแบ่งตลาดทั้งจังหวัดไม่ได้

ตัวกรอง **จังหวัดของหน่วยงานจัดซื้อ** มีครบ 77 จังหวัด เลือกหลายจังหวัดได้ด้วยช่องทำเครื่องหมาย; หากไม่เลือกเลยจะดูทุกรายการในฐานข้อมูล ตัวกรองและสัดส่วนผู้ชนะใช้จังหวัดของหน่วยจัดซื้อ ไม่ใช่จังหวัดที่ก่อสร้างจริง ซึ่งอาจต่างกัน พื้นที่งานที่ระบุได้จากชื่อประกาศยังแสดงแยกในตารางและรายละเอียด หากระบุไม่ได้จะแสดงว่า **ยังระบุไม่ได้** รายการโครงการแสดงหน้าละ 50 รายการ โดยเลือกเลขหน้าได้ ส่วนตัวเลขสรุปคำนวณจากทุกรายการที่ตรงตัวกรองในฐานข้อมูล

ใช้ Python 3.10 ขึ้นไปและโมดูลมาตรฐานเท่านั้น ไม่ต้องติดตั้งแพ็กเกจเพิ่ม โปรแกรมรับการเชื่อมต่อเฉพาะเครื่องนี้ (`127.0.0.1`) ยังไม่มีระบบล็อกอิน จึงยังไม่ควรเปิดให้คนอื่นเข้าทางเครือข่าย

## ฐานข้อมูลอยู่ที่ไหน

โปรแกรมสร้าง `data/egp.db` อัตโนมัติเมื่อรันครั้งแรก ไฟล์นี้เก็บโครงการทั้งหมด หากต้องการสำรองข้อมูล ให้หยุดโปรแกรมแล้วคัดลอกไฟล์นี้ไว้ในที่ปลอดภัย โฟลเดอร์ `data/` ถูกกันออกจาก Git เพื่อไม่ให้ข้อมูลจริงติดไปกับโค้ด

## นำเข้าข้อมูล CSV

ต้องเป็น UTF-8 มีหัวคอลัมน์ขั้นต่ำ `project_id,title,province,status` โดย `province` คือพื้นที่งาน และควรเพิ่ม `agency_province` เป็นจังหวัดหน่วยจัดซื้อเพื่อให้รายการนั้นค้นหาได้ด้วยตัวกรองจังหวัด หากไม่มีค่านี้ รายการยังแสดงเมื่อดูทุกจังหวัด แต่จะไม่ตรงกับจังหวัดที่เลือก ดูหัวคอลัมน์ครบใน [import_template.csv](examples/import_template.csv) ราคาใช้หน่วย **บาท** และวันที่ใช้ `YYYY-MM-DD` สถานะที่รองรับคือ `ประกาศใหม่`, `ระหว่างประมูล`, `ประกาศผู้ชนะ`, `ทำสัญญาแล้ว`, `ยกเลิก`, `ไม่ทราบสถานะ` ขนาดไฟล์สูงสุด 5 MB และไม่เกิน 5,000 รายการต่อครั้ง ถ้าแถวใดไม่ถูกต้อง ระบบจะไม่บันทึกทั้งไฟล์เพื่อให้แก้ก่อนนำเข้าใหม่ รหัสโครงการซ้ำจะอัปเดตรายการเดิม

ข้อมูลตัวอย่างมีรหัสขึ้นต้น `DEMO-` และแสดงป้ายบนเว็บ โปรแกรมไม่ให้ใช้รหัสลักษณะนี้กับข้อมูลจริง ปุ่ม **ลบตัวอย่าง** จะลบเฉพาะรายการตัวอย่าง ส่วนรายการจริงที่เพิ่มเองจะไม่ถูกลบ

ระบบเก็บที่มาของแต่ละรายการว่าเพิ่มด้วยมือ มาจาก CSV, API หรือเป็นข้อมูลตัวอย่าง และบันทึกประวัติการนำเข้า CSV 20 ครั้งล่าสุดที่ `http://127.0.0.1:8501/api/imports` โดยมีชื่อไฟล์ จำนวนรายการใหม่/อัปเดต เวลา และค่า SHA-256 ของไฟล์เพื่อใช้ตรวจสอบย้อนหลัง

## ขอบเขตของต้นแบบ

- หน้าเว็บกรองราคาได้ตามวงเงินงบประมาณ ราคากลาง หรือราคาที่ชนะ โดยใส่ราคาต่ำสุดและสูงสุดได้อย่างอิสระ
- สัดส่วนผู้ชนะคำนวณจาก **จำนวนงานที่ชนะ** ภายในพื้นที่และเงื่อนไขที่เลือก โดยนับหนึ่งโครงการเป็นหนึ่งงาน เฉพาะรายการที่มีสถานะประกาศผู้ชนะหรือทำสัญญาแล้วและมีชื่อผู้ชนะ แม้ไม่มีราคาที่ชนะก็ยังนับได้ ชื่อที่สะกดต่างกันยังถือเป็นคนละราย
- คลิกชื่อผู้ชนะในกราฟเพื่อดูโครงการภายใต้ตัวกรองเดียวกัน หน้าต่างแสดงราคาที่ชนะและวงเงินงบประมาณแยกกัน พร้อมยอดรวมราคาที่ชนะเฉพาะงานที่มีราคา และแบ่งรายการหน้าละ 50 งาน
- ลิงก์ประกาศต้นทางเป็นข้อมูลที่ผู้เพิ่มหรือนำเข้าต้องใส่เอง
- ยังไม่มีงานตั้งเวลาดึง API, แหล่งประกาศงานใหม่/ระหว่างประมูล, การอ่าน PDF ด้วย AI หรือระบบผู้ใช้ สิ่งเหล่านี้เป็นขั้นต่อไป

## แนวทางส่งมอบให้บริษัท

ส่งมอบโค้ด เอกสาร และไฟล์ฐานข้อมูลที่ต้องการย้าย โดย **ไม่ส่งไฟล์ `.env` ส่วนตัว** จากนั้นให้ฝ่าย IT ติดตั้ง Python บนเครื่องของบริษัทและทดลองรันจริง คีย์ API ของบริษัทต้องเก็บเป็นค่าตั้งค่าลับบนเครื่องนั้น ไม่ใส่ในโค้ดหรือ Git ก่อนเปิดใช้งานผ่านเครือข่าย ต้องเพิ่มระบบล็อกอิน สิทธิผู้ใช้ HTTPS และการสำรองข้อมูลอัตโนมัติ
