# ยืนยันช่องทางรับข้อมูลแบบระบบต่อระบบ

เงื่อนไขของโปรเจกต์คือเซิร์ฟเวอร์รับข้อมูลเองได้ทั้งหมด ไม่ต้องให้ผู้ใช้เปิดเครื่องหรือเข้ามายืนยันตัวตนเป็นครั้งคราว การทดลองปัจจุบันยังไม่ผ่านเงื่อนไขนี้ ดู SERVER_READINESS.md

## ข้อความสำหรับสอบถามเจ้าของระบบ

เรื่อง: สอบถามช่องทางเชื่อมโยงข้อมูลประกาศจัดซื้อจัดจ้าง e-GP สำหรับระบบอัตโนมัติ

ต้องการพัฒนาระบบติดตามประกาศจัดซื้อจัดจ้างและการเปลี่ยนแปลงสถานะ โดยเริ่มจากเชียงใหม่ เชียงราย และพะเยา วิธี e-bidding ประเภทจ้างก่อสร้าง และรองรับการเลือกปีงบประมาณ ข้อมูลสำคัญคือเลขโครงการ หน่วยจัดซื้อ ชื่อโครงการ สถานะ วันที่เชิญชวน กำหนดยื่นข้อเสนอ วงเงิน ราคากลาง และวันที่ประกาศผู้ชนะ

ปัจจุบันหน้าเว็บ e-GP มีการส่งออก CSV สูงสุด 1000 รายการ แต่การเรียกรายการและ CSV จากเซิร์ฟเวอร์ใหม่ยังถูกขอให้ยืนยันตัวตน จึงขอสอบถาม:

1. มี API หรือบริการส่งออกที่รองรับการรับข้อมูลจากเซิร์ฟเวอร์โดยไม่ใช้การยืนยันสำหรับมนุษย์หรือไม่ รวมถึงโครงการที่ยังอยู่ขั้นเชิญชวน
2. หากต้องสมัครใช้บริการหรือทำข้อตกลง ต้องติดต่อหน่วยงานใด และมีเงื่อนไขสำหรับผู้ประกอบการ/ผู้พัฒนาระบบอย่างไร
3. มีวิธีอนุญาตระบบที่ลงทะเบียน เช่น service credentials หรือ IP ที่ได้รับอนุญาตหรือไม่
4. รองรับการดึงข้อมูลที่เปลี่ยนแปลงตั้งแต่เวลาที่กำหนด และการเก็บชุดเริ่มต้นเกิน 1000 รายการอย่างไร
5. มีข้อกำหนดเรื่องความถี่ จำนวนคำขอ ค่าใช้จ่าย การเก็บรักษา และการนำข้อมูลไปแสดงต่ออย่างไร
6. มีเอกสารนิยามฟิลด์ โดยเฉพาะจังหวัด วันประกาศแต่ละขั้นตอน และวันปิดรับข้อเสนอหรือไม่

เอกสารนี้เป็นร่างสำหรับตรวจและใช้สอบถาม ยังไม่ได้ส่งถึงหน่วยงานใด และยังไม่มีการยืนยันว่ามีบริการดังกล่าวเปิดให้ใช้

## เกณฑ์ตรวจคำตอบหรือผู้ให้บริการข้อมูลรายอื่น

- ทดลองจากเซิร์ฟเวอร์ใหม่โดยไม่มีเซสชันจากเครื่องผู้ใช้ รับโครงการจริงได้และทำซ้ำต่างเวลาได้
- รับทั้งประกาศใหม่และการเปลี่ยนสถานะของโครงการเก่า ไม่ใช่เฉพาะข้อมูลสัญญาที่ลงนามแล้ว
- รู้วิธีแบ่งชุด/ตรวจยอดเมื่อข้อมูลเกินขีดจำกัด และมีนิยามความครบของแต่ละรอบ
- มีสิทธิ์ใช้งานและขีดจำกัดที่ชัดเจนก่อนเลือกเป็นแหล่ง production
- ไม่ใช้บริการที่อ้างว่าอัตโนมัติ แต่ยังต้องให้ผู้ใช้ส่ง cookie/token หรือยืนยัน CAPTCHA เป็นประจำ
