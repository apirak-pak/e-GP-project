# ฐานประกาศ e-GP ชุดใหม่

ระบบนี้แยกจาก DGA และฐาน `data/opportunities.db` เดิม หน้าเว็บอ่านเฉพาะ `data/egp_live.db` ซึ่งเริ่มว่าง ไม่โหลดตัวอย่างหรือข้อมูลเก่าเข้าอัตโนมัติ

## เริ่มใช้งานใน Edge

1. ที่โฟลเดอร์ `C:\DDDDDDDDDDDDD\e-GP project` เปิด PowerShell แล้วรัน `python -m egp_live.server` เปิดหน้าต่างนี้ค้างไว้
2. เปิด `http://127.0.0.1:8502/` **ใน Edge**
3. เปิด `edge://extensions` เปิด Developer mode กด **Load unpacked** แล้วเลือก `C:\DDDDDDDDDDDDD\e-GP project\egp_live\extension` หากติดตั้ง `e-GP Radar API Connector` รุ่นเก่าไว้ ให้ปิดรุ่นเก่าเพื่อลดการรบกวน
4. กลับหน้า `http://127.0.0.1:8502/` แล้วโหลดหน้าใหม่ กด **เชื่อมตัวรับ API**
5. เปิด [หน้าค้นหา e-GP](https://process5.gprocurement.go.th/egp-agpc01-web/announcement?keywordSearch=&advancedSearch=true) ใน Edge เดียวกัน ผ่านการตรวจ Cloudflare แล้วกดค้นหาให้ได้ผลหนึ่งครั้ง หากเปิดหลายแท็บ e-GP ให้เหลือแท็บค้นหาเพียงแท็บเดียว
6. กลับหน้าโปรแกรม เลือกปี 2569 และสามจังหวัด ใช้ **Manual** เริ่มที่หน้า 1 จำนวน 1 หน้า กด **ดึง API และบันทึก** เพื่อตรวจว่าตัวเชื่อมทำงาน ข้อมูลแต่ละหน้าจะบันทึกทันที
7. เลือก **อัตโนมัติ** แล้วกด **เริ่มดึงต่อเนื่อง** โปรแกรมจะอ่านหน้าถัดไปที่ยังขาดของแต่ละจังหวัดจากฐานในเครื่อง ไล่ API ทีละหน้าและบันทึกทีละหน้า เว้น 2.5 วินาทีระหว่างคำขอ หยุดจังหวัดนั้นเมื่อเจอหน้าว่าง และหยุดทั้งรอบเมื่อ e-GP ตอบ 429, ต้องยืนยันใหม่, ข้อมูลซ้ำข้ามหน้า หรือถึงหน้า 1000 กด **หยุดดึง** ได้ หากหยุดกลางทาง ให้ค้นหาใน e-GP ใหม่เมื่อจำเป็น แล้วเริ่มอัตโนมัติอีกครั้งเพื่อไปต่อจากหน้าที่บันทึกแล้ว
8. **Manual** ยังใช้ระบุหน้าเริ่มและจำนวนหน้าต่อรอบ 1, 3 หรือ 10 ได้ ใช้เมื่อต้องการดึงหน้าเก่าซ้ำเพื่ออัปเดต หรือทดลองหน้าเฉพาะ หากเคยเจอหน้าว่างแล้วแต่ข้อมูลต้นทางเพิ่มขึ้นภายหลัง ให้ใช้ Manual ตรวจหน้านั้นใหม่ก่อน

การดึงยาวทำงานอยู่ในแท็บ e-GP ของ Edge จึงต้องเปิด Edge และแท็บนั้นค้างไว้ โปรแกรมไม่ได้ทำงานเบื้องหลังเมื่อปิดเบราว์เซอร์ และไม่ข้าม Cloudflare หรือการจำกัดคำขอของ e-GP การดึงหลายหน้ากินเวลานานและผลการแบ่งหน้าอาจเปลี่ยนเมื่อมีประกาศใหม่เข้ามาระหว่างรอบ จึงต้องตรวจความครบกับเว็บต้นทาง ไม่ควรตีความหน้าว่างว่าเป็นหลักฐานถาวรว่าข้อมูลทั้งหมดครบ

หน้าเว็บกรองปี จังหวัด สถานะ และคำค้นใน **ข้อมูลที่เก็บบนเครื่อง** เท่านั้น การเปิดหรือกรองหน้าเว็บไม่ส่งคำขอไป e-GP ข้อมูล JSON ดิบระดับโครงการดูได้จากปุ่ม **ดู JSON ดิบ**; คำตอบเต็มของแต่ละหน้าอยู่ในตาราง `api_pages.response_json` และข้อมูลล่าสุดระดับโครงการอยู่ใน `projects.raw_json` ตัวเชื่อมส่งเฉพาะคำตอบ API โดยตัดฟิลด์ชื่อ token/cookie/authorization/password/secret; ไม่ส่ง header หรือ cookie เข้าโปรแกรม

วิธีนี้ยึดตัวเชื่อม Edge ที่เคยทดสอบได้ 30 รายการเป็นต้นแบบ ยังไม่ได้ยืนยันว่าจะดึงทุกหน้าได้ครบหรือจำนวนโครงการจะตรงกับผลค้นหาที่ e-GP ทุกเวลา ตรวจจำนวนและสถานะกับเว็บต้นทางก่อนใช้ตัดสินใจเสนอราคา ห้ามตีความคำว่า “ประกาศเชิญชวน” อย่างเดียวว่าเลยกำหนดยื่นข้อเสนอหรือยัง เพราะ API รายการนี้ยังไม่ได้ยืนยันวันปิดรับ
