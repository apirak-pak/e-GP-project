# ทดลอง DGA API ตามตัวกรอง e-GP: เชียงใหม่ / 2569 / e-bidding / จ้างก่อสร้าง

ตรวจวันที่ 21 ตุลาคม 2569 ด้วย **EGP-CONTRACT API ของ DGA เท่านั้น** (`GET https://opend.data.go.th/govspending/service/egp-contract`) ไม่อ่านตารางหรือคลิกหน้าเว็บ e-GP และไม่ใช้ RSS หรือส่วนขยาย Edge ในรอบนี้

## ฐานเก่าและฐานใหม่

- สำรองฐานเดิม `data/egp.db` ด้วย SQLite backup ที่ `data/backups/before_dga_raw_db_20261021_191906/egp_86204.db` ตรวจ `integrity_check=ok`, 86,204 โครงการ, SHA-256 `8aaf344b2da217f2f70c421921b0da6ca111c13691462fd8ad15f7c668cb7a71` รายละเอียดใน `manifest.json`
- ไฟล์ `data/egp.db` เดิมยังอยู่เป็นสำเนาอีกชุด แต่เว็บไม่อ่านแล้ว การย้ายไฟล์เดิมไปโฟลเดอร์สำรองติด Windows file lock จึงคงไว้แทนการฝืนลบหรือย้าย
- เว็บและตัวเก็บข้อมูลใช้ฐาน SQLite ใหม่ `data/dga_explore.db` ผ่าน `SQLITE_DB_FILE=dga_explore.db` ใน `.env` เฉพาะเครื่อง ฐานใหม่มีโครงการที่แปลงเพื่อแสดง **0**, คำตอบ DGA ดิบ **1 ชุด / 100 รายการ** ไม่แตะ Supabase
- ในโหมดนี้เว็บปิดการเพิ่มโครงการ/CSV/ข้อมูลตัวอย่าง และ `app.sync_egp` ไม่ยอมแปลงรายการลง `projects` ก่อนตัดสินใจเรื่องฟิลด์

## คำขอที่ส่งจริงและผล

ส่งหนึ่งคำขอ: `year=2569`, `keyword=เชียงใหม่`, `limit=100`, `offset=0` DGA ตอบ HTTP 200, `success=true`, ส่ง 100 รายการ และรายงาน `total=20,819` สำหรับ **คำขอนี้** จำนวน 20,819 ไม่ใช่จำนวนโครงการที่ตรงตัวกรองทั้งสี่ และ 100 รายการแรกไม่ใช่ชุดข้อมูลครบ

คำตอบ DGA แสดงพารามิเตอร์ `year`, `keyword`, `limit`, `offset`, `dept_code`, `winner_tin`, `budget_start`, `budget_end`; ไม่พบพารามิเตอร์จังหวัด/วิธีจัดหา/ประเภทงานในคำขอหรือ metadata ที่ตอบกลับ รอบนี้จึงใช้คำค้น `เชียงใหม่` เพื่อลดขอบเขตที่ API แล้วตรวจ **ค่าดิบแต่ละรายการในเครื่อง** ตาม `province=เชียงใหม่`, `project_type_name=จ้างก่อสร้าง`, `purchase_method_name=ประกวดราคาอิเล็กทรอนิกส์ (e-bidding)` คำค้นอาจไม่ครอบคลุมงานทั้งหมดที่หน่วยงานอยู่เชียงใหม่แต่ชื่อไม่มีคำนี้

| เงื่อนไขใน 100 รายการที่ได้รับ | จำนวน |
|---|---:|
| `province=เชียงใหม่` | 56 |
| `project_type_name=จ้างก่อสร้าง` | 86 |
| `purchase_method_name` เป็น e-bidding | 92 |
| ตรงทั้งสามข้อ | **47** |

ทั้ง 47 รายการมี `contract` และชื่อผู้ชนะ รวม 51 สัญญา; `project_status` เป็น `ระหว่างดำเนินการ` ทั้ง 47 จึงอ่านว่า “กำลังเปิดให้เข้าประมูล” จากค่านี้ไม่ได้ บริการนี้ให้ข้อมูลโครงการ/สัญญา ส่วน `year=2569` ตามนิยามที่ใช้กับ EGP-CONTRACT คือปีงบประมาณของสัญญา ไม่ยืนยันว่าเทียบเท่าตัวกรองปีงบประมาณบนหน้า e-GP

## ฟิลด์ที่ได้รับจริงและน่าใช้

ฟิลด์ระดับโครงการต่อไปนี้มีค่าในตัวอย่างที่ตรง 47 รายการครบ 47/47 (ความครบนี้ใช้ได้เฉพาะตัวอย่าง ไม่รับประกันทุกหน้า):

| กลุ่ม | ฟิลด์ดิบ | ใช้ทำอะไร / ข้อควรระวัง |
|---|---|---|
| ตัวตน | `project_id`, `project_name` | เลขและชื่อโครงการสำหรับค้นหา/แสดงผล |
| คัดกรอง | `year`, `project_type_name`, `purchase_method_name`, `purchase_method_group_name` | กรองปี ประเภท วิธีจัดหา; ปีนี้เป็นปีของข้อมูลสัญญา |
| หน่วยงาน/พื้นที่ | `dept_name`, `dept_sub_name`, `province`, `district`, `subdistrict`, `project_location.lat`, `project_location.lon`, `geom` | แสดงหน่วยงานและที่ตั้งที่ DGA ส่งมา; จังหวัด/พิกัดยังไม่ยืนยันว่าเป็นพื้นที่ก่อสร้างจริง |
| วันที่/สถานะ | `announce_date`, `transaction_date`, `project_status` | วันที่ประกาศ วันที่รายการ และสถานะดิบ; `ระหว่างดำเนินการ` ไม่ใช่สถานะรับข้อเสนอ |
| ราคา | `project_money`, `price_build`, `sum_price_agree` | งบประมาณ ราคากลาง ราคารวมที่ตกลงจ้าง |
| สัญญา | `contract[].contract_no`, `contract[].contract_date`, `contract[].contract_finish_date`, `contract[].price_agree`, `contract[].status`, `contract[].winner_name`, `contract[].winner_tin` | เลข/วัน/ราคาสัญญาและผู้ชนะ; หนึ่งโครงการอาจมีหลายสัญญา |

**ไม่พบใน 20 ฟิลด์ระดับโครงการและฟิลด์สัญญาที่ได้รับ:** วันและเวลาสิ้นสุดการยื่นข้อเสนอ, สถานะประกาศเชิญชวนแบบละเอียด, วันเปิดซอง/วันประมูล, เกณฑ์พิจารณา, ผลงานขั้นต่ำ, เอกสาร TOR และลิงก์เอกสารต้นทาง จึงยังทำการ์ด “งานที่กำลังเปิดรับประมูล” ให้เชื่อถือได้จาก EGP-CONTRACT ชุดนี้อย่างเดียวไม่ได้

## หลักฐานที่เก็บไว้

- ฐานใหม่ `data/dga_explore.db`: ตาราง `dga_raw_captures.response_body` เก็บคำตอบ JSON ครบ (ปิดเฉพาะ API Key ที่ DGA แนบกลับมา), `dga_raw_projects.raw_json` เก็บรายการแยกทีละแถวแบบไม่แปลง
- ไฟล์ชุดเดียวกัน `data/dga_raw/20261021_192038_582822_year2569_offset0/response.json`, `manifest.json`, `field_inventory.json`, `FIELDS.md`
- SHA-256 ของคำตอบในฐานตรงกับ `response.json`, ตรวจ `integrity_check=ok` และตรวจว่าไม่มี API Key อยู่ในฐานใหม่
- เว็บ `http://127.0.0.1:8501/` ตอบ `raw_mode=true`, `raw_captures=1`, `raw_projects=100`, `projects=0`; การ POST นำเข้าข้อมูลที่แปลงแล้วตอบ 409

หากจะสำรวจเพิ่ม ควรตกลงก่อนว่าต้องการจังหวัดของหน่วยจัดซื้อหรือจังหวัดที่ทำงานจริง และต้องการปีงบประมาณประกาศหรือปีสัญญา การดึงเพิ่มต้องแบ่งหน้าและตรวจความครบ เพราะรอบนี้มีเพียงหน้าแรก 100 จาก 20,819 ผลของคำค้น `เชียงใหม่` เท่านั้น
