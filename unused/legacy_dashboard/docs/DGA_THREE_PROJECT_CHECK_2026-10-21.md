# ตรวจ 3 โครงการจากภาพ e-GP ใน DGA EGP-CONTRACT

ตรวจวันที่ 21 ตุลาคม 2569 เวลาประมาณ 19:33–19:36 น. (ไทย) ด้วย `GET https://opend.data.go.th/govspending/service/egp-contract` โดยตรงเท่านั้น เลขโครงการอ่านจากภาพที่ผู้ใช้ส่ง ไม่อ่านหรือดึงตารางจากเว็บ e-GP ในรอบนี้

| เลขโครงการจากภาพ | สถานะที่เห็นในภาพ e-GP | `year=2569`, `keyword=เลขโครงการ` | `year=2570`, `keyword=เลขโครงการ` |
|---|---|---:|---:|
| `69109071515` | หนังสือเชิญชวน/ประกาศเชิญชวน | HTTP 200, `total=0` | HTTP 200, `total=0` |
| `69109069424` | หนังสือเชิญชวน/ประกาศเชิญชวน | HTTP 200, `total=0` | HTTP 200, `total=0` |
| `69109035949` | อนุมัติสั่งซื้อสั่งจ้างและประกาศผู้ชนะการเสนอราคา | HTTP 200, `total=0` | HTTP 200, `total=0` |

ทดสอบวิธีค้นเลขโครงการกับ `69029010512` ซึ่งทราบว่าอยู่ในคำตอบ DGA ปี 2569: `keyword=69029010512` ได้ HTTP 200, `total=1`, และคืนเลขโครงการตรงกัน จึงไม่ใช่กรณีที่ `keyword` ค้นเลขโครงการไม่ได้

ตรวจ `year=2570` โดย **ไม่ระบุคำค้น** และ `limit=1`: API ตอบ HTTP 200, `total=0` ขณะตรวจ นี่เป็นหลักฐานว่า EGP-CONTRACT ยังไม่ส่งข้อมูลปีสัญญา 2570 ผ่านคำขอนี้ ไม่ใช่หลักฐานว่า e-GP ไม่มีโครงการปี 2570

ตรวจความเปลี่ยนแปลงระหว่างวันด้วยคำขอเดียวกัน `year=2569`, `keyword=จ้างก่อสร้าง`, `limit=20`, `offset=0`: ตอน 02:13 น. และรอบนี้ API รายงาน `total=87,597` เท่ากัน และคำตอบ JSON เหมือนกันทุกไบต์ ผลนี้บอกได้เพียงว่า **ตัวอย่างคำขอนี้ไม่เปลี่ยนในช่วงที่เปรียบเทียบ** ไม่พิสูจน์ว่าบริการไม่อัปเดตเลย ในตัวอย่าง 100 โครงการที่ดึงก่อนหน้า มีวันทำสัญญาถึง 30 กันยายน 2569; ยังไม่พบความถี่หรือเวลาหน่วงการอัปเดต API ที่ยืนยันได้

ผลสรุปที่รองรับหลักฐาน: ณ เวลาตรวจ **ไม่พบทั้งสามเลขใน EGP-CONTRACT สำหรับปีสัญญา 2569 และ 2570** บริการนี้เน้นข้อมูลโครงการ/สัญญา จึงใช้ตรวจประกาศเชิญชวนปัจจุบันให้ครบไม่ได้ แม้โครงการที่ e-GP แสดงผู้ชนะแล้ว ก็อาจยังไม่ปรากฏในบริการสัญญา ผลนี้ไม่ครอบคลุม API อื่นทั้งหมดของ DGA

คำตอบดิบทุกคำขอถูกเก็บใน `data/dga_explore.db` ตาราง `dga_raw_captures` และโฟลเดอร์ `data/dga_raw/` พร้อมปิด API Key ที่ DGA แนบคืน; ไม่มีการแปลงข้อมูลขึ้นเว็บหรือแก้ฐานเดิม
