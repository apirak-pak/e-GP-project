# จุดเริ่มใหม่: เก็บ DGA ดิบก่อนเลือกข้อมูลแสดงผล

> เอกสารนี้บันทึกสถานะก่อนงาน [ฐานใหม่และการทดลองตัวกรองเชียงใหม่](DGA_FILTER_PROBE_2026-10-21.md) สถานะปัจจุบันใช้ `data/dga_explore.db` และสำรองฐานเดิมแล้ว

## กลับไปตรงไหน

ยึดเวอร์ชัน **แดชบอร์ด DGA ก่อนเพิ่มหน้าโอกาสประมูล** ตามข้อความของผู้ใช้ “มีข่าวร้ายมาบอก เหมือน field ข้อมูลที่ดึงตอนนี้มันมาไม่ถูก” ในแชต “ออกแบบแดชบอร์ดติดตาม e-GP” (thread `01a10ca1-8071-72b1-8d01-a1e25805c458`, turn `01a159ce-731b-7101-a5ce-56065b34b203`)

ตรวจ Git แล้วมีสอง commit โดยตัวล่าสุด `fc76dd2` เป็นแกนแดชบอร์ดก่อนงานโอกาสประมูล ความเปลี่ยนแปลงใน `app/server.py` และ `app/web/index.html` หลัง commit นี้เป็นส่วนหน้าทดลอง จึงคืนสองไฟล์และ README จาก commit นี้ แล้วเพิ่มเฉพาะคำอธิบายการเก็บ DGA ดิบ ไม่ reset Git ทั้ง repository และไม่ย้อนฐานข้อมูล

## ถอดอะไรออกจากเว็บแล้ว

- หน้าโอกาสประมูล `/opportunities` และข้อมูลที่อ่านจากตารางหน้า e-GP
- หน้า RSS `/live`
- ตัวเชื่อม API ผ่านส่วนขยายเบราว์เซอร์ รวม endpoint จับคู่และนำเข้า
- หน้าเปรียบเทียบ GBIDs `/dga-preview`
- โมดูล ไฟล์หน้าเว็บ เอกสาร/ชุดตัวอย่าง/การทดสอบของส่วนข้างต้น ย้ายออกจากชุดโค้ดที่ใช้งานแล้ว

หน้าเว็บคงเหลือแดชบอร์ด DGA เดิมที่ `http://127.0.0.1:8501/` ตัวกรอง รายการโครงการ และสัดส่วนผู้ชนะตามข้อมูลที่นำเข้า ไม่มีการดึงข้อมูล e-GP หรือ RSS ขณะเปิดหน้าเว็บ

ส่วนขยายที่เคยติดตั้งใน Edge ไม่ได้ถูกถอนออกจากการตั้งค่าเบราว์เซอร์ แต่โปรแกรมไม่มี endpoint รับหรือปุ่มสั่งงานส่วนขยายนั้นแล้ว

## ข้อมูลเดิมและสำรอง

- ฐานหลักยังเป็น SQLite ในเครื่อง `data/egp.db` **86,204 โครงการ** เป็นข้อมูล DGA เดิมที่ผ่านการแปลงแล้ว ไม่แก้หรือลบในงานรอบนี้
- `data/opportunities.db` ยังเก็บอยู่ แต่ไม่ได้เชื่อมกับหน้าเว็บ
- สำรองก่อนเปลี่ยน: `data/archives/pre_dga_reset_20261021_021048/`
- `source_before_reset.zip` เก็บโค้ดและเอกสารก่อนถอดส่วนใหม่ ไม่มี `.env` หรือฐานข้อมูล
- สำรอง SQLite แบบ consistent backup แยกเป็น `egp.db` และ `opportunities.db` ในโฟลเดอร์สำรอง
- `removed_features/` เก็บไฟล์ที่ย้ายออกพร้อมตำแหน่งเดิม; `manifest.json` บันทึกจุดอ้างอิงและรายการไฟล์ สามารถเลือกนำกลับภายหลังได้ ไม่จำเป็นต้องย้อนทั้งโปรแกรม
- ไม่เปลี่ยนค่าเชื่อมต่อหรือข้อมูลใน Supabase

## ตัวเก็บข้อมูลใหม่

ใช้ `python -m app.capture_dga --year 2569 --limit 20` หนึ่งการรันคือหนึ่งคำขอ ไม่ลองซ้ำอัตโนมัติ ไม่เรียกการแปลงของ `to_project` ไม่เปิดหรือเขียนฐานข้อมูล

แต่ละชุดใน `data/dga_raw/` มี:

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `response.json` | คำตอบเต็มจาก API เก็บโครงการและสัญญาครบทุกฟิลด์ ปิดเฉพาะ API Key ที่ DGA สะท้อนคืน |
| `manifest.json` | ปี คำค้น limit/offset เวลา HTTP จำนวนรายการ SHA-256 และยืนยันว่ายังไม่ได้ map/import |
| `field_inventory.json` | รายการ path ชนิด จำนวนครั้งที่พบ/มีค่า และตัวอย่างค่า |
| `FIELDS.md` | ตารางสำหรับอ่านและตัดสินใจว่าจะนำฟิลด์ใดไปใช้ |

วันที่ในข้อมูลคงข้อความต้นฉบับ เช่น พ.ศ. แบบไทย สถานะ `ระหว่างดำเนินการ` คงเดิม ไม่เปลี่ยนเป็นเปิดประมูลหรือทำสัญญาแล้ว ไม่เดาจังหวัดจากชื่อ และยังไม่เลือกตัดฟิลด์ที่ไม่แสดงบนหน้าเว็บ

## ผลดึงตัวอย่างจริง

วันที่ 21 ตุลาคม 2569 เวลาประมาณ 02:13 น. (ไทย), คำค้น `จ้างก่อสร้าง`, limit 20, offset 0:

| ปีที่ทำสัญญา | HTTP | ได้รายการ | จำนวนผลที่ API รายงาน | โฟลเดอร์ |
|---|---|---|---|---|
| 2569 | 200 | 20 | 87,597 | `data/dga_raw/20261021_021334_260082_year2569_offset0/` |
| 2570 | 200 | 0 | 0 | `data/dga_raw/20261021_021335_443588_year2570_offset0/` |

ชุดปี 2569 พบ 20 ฟิลด์ระดับโครงการ รวมรายการสัญญา และ inventory รวม nested paths 30 รายการ สถานะดิบทั้ง 20 คือ `ระหว่างดำเนินการ` จังหวัดที่ได้รับคือกรุงเทพมหานคร นครราชสีมา และนนทบุรี ไม่ได้อ้างว่าครอบคลุมสามจังหวัดเป้าหมายหรือข้อมูลทั้งปี ผลปี 2570 เป็นศูนย์เฉพาะบริการและเงื่อนไขที่ทดลอง ไม่พิสูจน์ว่าไม่มีงานประกาศปี 2570 ใน e-GP

รอบแรกอีกหนึ่งคำขอของปี 2569 หยุดก่อนบันทึกเพราะตรวจพบ key สะท้อนคืน จึงปรับตัวเก็บให้ปิด key และรันชุดที่สำเร็จข้างต้น รวมคำขอจริงของงานรีเซ็ตครั้งนี้ 3 ครั้ง ไม่รวมการทดสอบด้วยข้อมูลจำลอง ไฟล์หลักฐานทดลองเดิมสองไฟล์ที่มี request metadata ถูกปิด key แล้วด้วย

## ลำดับงานต่อจากนี้

1. อ่าน `FIELDS.md` คู่กับ `response.json` เพื่อทำความเข้าใจนิยามและค่าจริง
2. เลือกฟิลด์ที่ต้องเก็บถาวร/แสดง โดยเก็บสำเนาดิบเป็นหลักฐาน และแยกค่าดิบกับค่าที่คำนวณขึ้น
3. ตกลงขอบเขตปี จังหวัด และวิธีตรวจความครบ ก่อนดึงเป็นชุดใหญ่หรือปรับหน้าเว็บ

ยังไม่ขยายการดึงให้ครบทั้งประเทศหรือสามจังหวัด และยังไม่ออกแบบหน้าใหม่จากการคาดเดาฟิลด์

ทดสอบตัวเก็บดิบเรื่องคงค่าข้อมูล ปิด key ไม่เขียน DB และไม่ลองซ้ำเมื่อ 429 พร้อมชุดทดสอบแดชบอร์ดเดิม รวม 9 กรณีผ่าน
